## Linux guide

Run these commands — **Debian distros only**.

1. Install luarocks:

   ```bash
   sudo apt install luarocks
   ```

2. Install luasocket:

   ```bash
   sudo luarocks install luasocket
   ```

That's basically it — it just gives you a wait function, lol.
