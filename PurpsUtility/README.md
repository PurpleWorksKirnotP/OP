# Purps Utility

> Here is where I store my utilities for making scripts. Don't go snooping in here
> unless you know what you're doing.

Everything here needs an executor that supports `loadstring`, `gethui` and `Drawing`
(Synapse-style executors and most modern free ones).

| Script | Notes |
| --- | --- |
| `PurpsUtility.lua` | All in one (DEX, Inf Yield, Aimbot, etc) |
| `Aimlock.lua` | Aimlock V1 — old, discontinued, bad UI |
| `AimlockV2.lua` | Aimlock V2 — new UI |
| `AimlockBETA.lua` | Aimlock BETA 0.0.5 — same UI, new features |

---

## All in one

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/PurpleWorksKirnotP/PurpleScripts/refs/heads/main/PurpsUtility/PurpsUtility.lua"))()
```
